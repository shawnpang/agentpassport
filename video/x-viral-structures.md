# X viral video structures for Agent Passport
Scanned 2026-10-25. For design/video; commit to `shawnpang/agentpassport/video/`.

## Patterns that travel (steal structure, not pixels)

### 1. One-capability punch (Cursor style)
- 1 line what it does → immediate UI close-up of the action → soft CTA
- Examples: [Cursor canvases](https://x.com/cursor_ai/status/2111193957527146711) (~2.6k likes), [phone control agents](https://x.com/cursor_ai/status/2107618653701296162) (~2.3k likes)
- **Use for:** Issue passport / Mint card / Simulate call each as a 8–12s cut

### 2. Mute UI + big captions (Linear / Notion launch feel)
- No voice required; captions carry the story
- Matches our locked script: Verify → Account → Card+Phone → Freeze/Revoke → CTA
- Best for landing embed (autoplay muted)

### 3. Same-source site + video
- One mockup system drives both the landing and the MP4 (see community pattern around product-launch motion kits, e.g. [repo list post](https://x.com/Mnilax/status/2109314840057565345))
- **Rule:** if the passport page UI isn’t locked, don’t render final video

### 4. Avoid on X
- Hype EDM + neon gradients
- Face-cam founder rant without product UI
- Fake phone shells with invented dashboards
