## X punch（约 15–18s）砍法

1. Stuck — hotel won’t trust the agent  
2. Verify once → Passport（委托可见）  
3. Hotel recognizes mandate → booked  
4. Revoke · authority wiped · Request access  

---

## 明确不要

- Mint / 开卡庆祝页当高潮  
- Act 整屏电话 / OTP  
- Revoke 主视觉放大张 BURNED 卡  
- 「我们是银行 / 已经处处可用」  

## 明确要

- Authorize = **Spend proof**（证明授权，不是卖点）  
- Act = **Hotel recognizes … mandate**  
- Revoke = **权限掉光看得见**  
- 连续光标干活感（下轮实录债）
