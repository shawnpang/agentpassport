# AllScale → Agent Passport taste brief
Source: https://www.allscale.io/ (reviewed 2026-10-25)

## Steal from Allscale
- White / near-white canvas, black type (#0c0c0c), company green accent (~`#00c96d` focus green; mint surfaces `#f4f8f5`)
- Product UI as hero (real screens / cards), not abstract crypto art
- Embedded live demo block ("Try out our demo") — matches our four-step Simulated demo
- Short how-it-works: 1 / 2 / 3 steps
- Pill CTAs, lots of air, Webflow-clean layout

## Upgrade for Bay Area taste (don’t clone wholesale)
- AllScale copy is long and "fintech brochure"; Agent Passport needs Cursor/Resend brevity + developer code in hero
- Avoid sea-video / stock lifestyle filler; keep passport credential metaphor
- Prefer Linear/Granola typography hierarchy over generic marketing paragraphs
- Two palette options for founder pick:
  1. **White + AllScale green** (default, closest to current brand)
  2. **Black + green** (more Cursor/Vercel; use sparingly for demo theater section)
